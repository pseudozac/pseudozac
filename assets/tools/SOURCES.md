# Tool mark sources
Reviewed 2026-10-19. All assets are local SVG wrappers containing normalized PNG copies of the source artwork. They do not load remote images, fonts, scripts, or trackers. Logo aspect ratios and normal-state colors are preserved; brief decorative glitch copies are clipped over them. Reduced-motion users see the static mark.

Product names remain native README text. Some products use their vendor mark (for example Splunk SOAR and Cortex XSOAR); these are not claimed to be dedicated product logos. Website favicons are the versions currently served by the vendor, not a guarantee that every marketing channel uses the same revision.
