# Profile artwork

The main banner, section headers, circuit footer, and social button frames are repository-local SVGs. They contain no scripts, trackers, remote fonts, or external image dependencies. The animated artwork includes reduced-motion support.

## Social logo sources

The social buttons preserve the original logo path geometry from [Simple Icons 3.0.0](https://github.com/simple-icons/simple-icons/tree/3.0.0/icons), distributed under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/3.0.0/LICENSE.md). Brand marks belong to their respective owners; their appearance here identifies links and does not imply endorsement.

Tool badges continue to use Shields.io, as in the previous profile. Brand logos are retained where available; existing emoji fallbacks are retained for tools without a supported logo. They are decorative labels, not live telemetry or a claim of certification.
