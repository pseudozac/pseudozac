# Profile artwork

The main banner, section number accents, circuit divider, and unframed social marks are repository-local SVGs. They contain no scripts, trackers, remote fonts, or external image dependencies. The animated artwork includes reduced-motion support.

## Social logo sources

The social marks preserve the original logo path geometry from [Simple Icons 3.0.0](https://github.com/simple-icons/simple-icons/tree/3.0.0/icons), distributed under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/3.0.0/LICENSE.md). Brand marks belong to their respective owners; their appearance here identifies links and does not imply endorsement.

- [Instagram](https://github.com/simple-icons/simple-icons/blob/3.0.0/icons/instagram.svg)
- [LinkedIn](https://github.com/simple-icons/simple-icons/blob/3.0.0/icons/linkedin.svg)
- [GitHub](https://github.com/simple-icons/simple-icons/blob/3.0.0/icons/github.svg)

Tool badges continue to use Shields.io, as in the previous profile. Brand logos are retained where available; existing emoji fallbacks are retained for tools without a supported logo. They are decorative labels, not live telemetry or a claim of certification.

## Compact presentation

Section titles use native Markdown text for theme-aware readability and mobile scaling. The SVGs beside them are small number accents, with no panel backgrounds. Social marks have transparent backgrounds, theme-aware main fills, cyan/magenta offsets, staggered glitch animation, and a static reduced-motion fallback. The footer is a fine circuit divider followed by native text. No personal or repository settings are changed.
