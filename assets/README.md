# Profile artwork

The main banner is the isaak-iz-cyber-banner.svg. It retains the revised character, scrolling code, fading bottom edge, IZ badge, and reduced-motion styles.

Section number accents, unframed social marks, circuit divider, and tool mark wrappers are repository-local SVGs. They contain no scripts, trackers, remote fonts, or external image references. Animations support reduced motion. Section headings and tool names are native Markdown/HTML text.

## Social logo provenance
Social marks preserve the original logo geometry from [Simple Icons 3.0.0](https://github.com/simple-icons/simple-icons/tree/3.0.0/icons), distributed under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/3.0.0/LICENSE.md). Their backgrounds are transparent and their main fills adapt to the color scheme. Cyan/magenta glitch copies are staggered between logos.

## Tools
The Shields.io badges and emoji stand-ins have been removed. See [tool mark sources](tools/SOURCES.md) for the vendor URLs, review date, product-vs-vendor distinctions, and legacy exception. Brand marks belong to their owners.
